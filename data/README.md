# Raw data from Kaggle

https://www.kaggle.com/datasets/jvanelteren/boardgamegeek-reviews/data

Download and extract the data into the `raw/` folder and then you can run the `utils/process_raw_game_detailed_data.py` script to generate processable data/rows in `processed/`

## Data Folder Setup

The `data/` folder now contains the data parsing scripts inside `utils/`.
To run the parsing scripts, ensure the dependencies from `requirements.txt` inside this folder are installed.
